# BÀI TẬP 2 – REACT NATIVE

## Bài tập 01: FASHION STORE

**Sinh viên:** Nguyễn Quốc Huy

**Tên ứng dụng:** MyApp_V2

### 1. Giới thiệu
Ứng dụng FASHION STORE được xây dựng bằng React Native (Expo), dùng để giới thiệu và hiển thị danh sách quần áo.

### 2. Link ứng dụng Expo
https://snack.expo.dev/@baidau/myapp_v2

### 3. Cấu trúc component
- App.js: Component chính.
- Header.js: Hiển thị tên cửa hàng.
- Home.js: Hiển thị trang chủ.
- Main.js: Hiển thị danh sách sản phẩm.
- Footer.js: Hiển thị thông tin liên hệ.

### 4. Các bước thực hiện
1. Tạo dự án MyApp_V2 trên Expo Snack.
2. Tạo thư mục components.
3. Tạo các file Header.js, Home.js, Main.js, Footer.js.
4. Import các component vào App.js.
5. Chạy và kiểm tra ứng dụng.
6. Lưu mã nguồn và tải lên GitHub.

### 5. Chức năng chính
- Hiển thị cửa hàng FASHION STORE.
- Hiển thị danh sách quần áo và giá bán.
- Hiển thị thông tin liên hệ.
- Hiển thị các mục Trang chủ, Sản phẩm, Giỏ hàng, Cá nhân.

### 6. Kết luận
Qua bài thực hành, em đã biết cách tạo dự án React Native, tổ chức component và chạy ứng dụng bằng Expo Snack.
