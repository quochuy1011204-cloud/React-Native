# BÀI TẬP 5 Thiết kế giao diện có hiệu ứng động

## 1. Giới thiệu
Ứng dụng theo dõi mục tiêu học tập được xây dựng bằng React Native và Expo Snack.

## 2. Chức năng
- Chọn nhiều bài học.
- Theo dõi tiến độ từ 0% đến 100%.
- Mỗi lần nhấn nút tăng 25%.
- Hiển thị thông báo khi hoàn thành.
- Nút đổi màu và học lại từ đầu.

## 3. Các Component
- `ProgressCard.js`: Hiển thị tiến độ học tập.
- `ActionButton.js`: Nút bắt đầu và học lại.
- `AnimatedMessage.js`: Hiển thị thông báo hoàn thành có hiệu ứng.


## 4. Link ứng dụng
- Tên ứng dụng: AnimateApp
- Link Expo: https://snack.expo.dev/@baidau/animateapp
