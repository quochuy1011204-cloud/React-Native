# BÀI TẬP 2 - THIẾT KẾ TRANG CHỦ ỨNG DỤNG HỌC TẬP

**Sinh viên:** Nguyễn Quốc Huy  
**Mã sinh viên:** CD-CNTT18A16  
**Lớp:** CD-CNTT18A

## 1. Giới thiệu
Xây dựng giao diện trang chủ ứng dụng học tập bằng React Native trên nền tảng Expo.

**Tên ứng dụng:** LearningApp

**Link ứng dụng Expo:**  
https://snack.expo.dev/@baidau/9fdb1a

## 2. Các thành phần đã xây dựng

Ứng dụng gồm 4 component chính:

- **Header.js:** Hiển thị tên ứng dụng và thông tin sinh viên.
- **StatCard.js:** Hiển thị thống kê khóa học, đang học và hoàn thành.
- **CourseCard.js:** Hiển thị danh sách các môn học, giảng viên và tiến độ học tập.
- **BottomMenu.js:** Tạo thanh menu phía dưới gồm Trang chủ, Khóa học, Thông báo và Cá nhân.

## 3. Các bước thực hiện

**Bước 1:** Tạo ứng dụng mới trên Expo Snack và đặt tên LearningApp.

**Bước 2:** Tạo các component Header, StatCard, CourseCard và BottomMenu.

**Bước 3:** Viết code cho từng component và thiết kế giao diện.

**Bước 4:** Kết nối các component trong App.js.

**Bước 5:** Chỉnh sửa màu sắc, bố cục và kích thước để giao diện đẹp, dễ nhìn.

**Bước 6:** Kiểm tra ứng dụng trên Expo Web và hoàn thiện giao diện.

## 4. Kết quả

Ứng dụng đã hiển thị đầy đủ các thành phần theo yêu cầu bài tập. Giao diện chạy thành công trên Expo Web.
