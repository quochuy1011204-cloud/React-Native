# BÀI TẬP 3: PRODUCT APP

## 1. Giới thiệu

Xây dựng ứng dụng bán sách bằng React Native và Expo.

Ứng dụng có tên **ProductApp – THẾ GIỚI SÁCH**, hiển thị danh sách các sản phẩm sách với hình ảnh, tên sách, giá bán và mô tả.

## 2. Link ứng dụng Expo

https://snack.expo.dev/@baidau/productapp

## 3. Các chức năng đã thực hiện

- Hiển thị tiêu đề THẾ GIỚI SÁCH.
- Hiển thị lời chào và giới thiệu cửa hàng sách.
- Hiển thị danh sách sản phẩm sách.
- Mỗi sản phẩm có hình ảnh, tên sách, giá và mô tả.
- Thiết kế giao diện các sản phẩm dạng lưới.
- Sử dụng component ProductCard để hiển thị sản phẩm.
- Truyền dữ liệu sản phẩm thông qua props.
- Sử dụng map() để hiển thị danh sách sản phẩm.

## 4. Các file code

### App.js
- Khai báo dữ liệu sản phẩm sách.
- Import component ProductCard.
- Hiển thị tiêu đề và nội dung giới thiệu.
- Sử dụng map() để hiển thị danh sách sản phẩm.

### ProductCard.js
- Tạo component ProductCard.
- Nhận dữ liệu sản phẩm thông qua props.
- Hiển thị hình ảnh, tên sách, giá và mô tả.
- Sử dụng StyleSheet để thiết kế giao diện.
